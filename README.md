# Claude Desktop AppImage

> **This repository is deprecated and no longer maintained.**

Anthropic now ships an official Claude Desktop for Linux, so repacking the
Windows build into an AppImage is no longer necessary.

- **Official `.deb` package from Anthropic** —
  [Claude Desktop on Linux](https://code.claude.com/docs/en/desktop-linux)
- **Gentoo overlay** (`app-misc/claude-desktop-bin`) —
  [cono/gentoo-portage](https://github.com/cono/gentoo-portage)

The existing releases and build scripts are left in place for reference. They
receive no further updates, and the automated daily builds have been turned off.
